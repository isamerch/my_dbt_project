# my_dbt_project

My first dbt project, built during the Analytics Engineer training at [DataBird](https://www.data-bird.co/). It is a learning project used to practise the fundamentals of dbt, before the final project ([local_bike](https://github.com/isamerch/local_bike)).

## What I practised

- **Project setup:** initialising a dbt project and connecting it to the data warehouse
- **Model layers:** organising models into staging, intermediate and marts
- **Configuration files:** `dbt_project.yml` and YAML files for sources and models
- **Tests:** generic tests (such as `unique` and `not_null`) on key columns
- **Documentation and lineage:** column descriptions and the dbt lineage graph
- **CI/CD:** dbt jobs for automated runs and tests
